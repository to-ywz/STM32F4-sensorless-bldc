# FOC L3.1 — PWM 硬件接口调研

## 1. 目标

明确算法输出的 `cmp_a/b/c` 如何进入真实 MCU 定时器和驱动链路。

**核心问题：**
- `cmp_a/b/c` 如何映射到 TIM CCR？
- PWM 频率、对齐方式、死区、互补输出如何配置？
- 如何安全启动和故障处理？

## 3. SVPWM 输出与定时器映射

### 3.1 当前 SVPWM 输出

当前 `svpwm_update()` 输出：

```c
typedef struct {
    int cmp_a;  // A 相比较值
    int cmp_b;  // B 相比较值
    int cmp_c;  // C 相比较值
} svpwm_pwm_t;
```

**范围：** 0 ~ PERIOD（当前 PERIOD = 1000）

### 3.2 映射到 TIM CCR

**目标：** 将 `cmp_a/b/c` 映射到 TIMx->CCR1/CCR2/CCR3

**映射关系：**

| SVPWM 输出 | TIM CCR | 电机相 |
|---|---|---|
| cmp_a | TIMx->CCR1 | U 相 |
| cmp_b | TIMx->CCR2 | V 相 |
| cmp_c | TIMx->CCR3 | W 相 |

**已确认映射：**

| SVPWM 输出 | TIM CCR | 引脚 | 电机相 |
|---|---|---|---|
| cmp_a | TIM1->CCR1 | PA8 (U+) / PA7 (U-) | U 相 |
| cmp_b | TIM1->CCR2 | PE11 (V+) / PE10 (V-) | V 相 |
| cmp_c | TIM1->CCR3 | PE13 (W+) / PE12 (W-) | W 相 |

**待确认：**
- [ ] 是否需要反转极性（高电平有效 vs 低电平有效）

### 3.3 period 与 ARR 的关系

**当前 SVPWM：**
- `PERIOD = 1000`
- `cmp_a/b/c` 范围：0 ~ 1000

**STM32 定时器：**
- ARR（Auto Reload Register）决定 PWM 周期
- CCR（Capture/Compare Register）决定占空比

**映射方案：**

| 方案 | period 含义 | ARR 值 | CCR 映射 |
|---|---|---|---|
| A | period = ARR | 1000 | CCR = cmp |
| B | period = 半周期（中心对齐） | 999 | CCR = cmp |

**待确认：**
- [ ] 中心对齐模式下，ARR 是半周期还是全周期？
- [ ] 当前 PERIOD=1000 对应 ARR=1000 还是 ARR=999？

## 4. PWM 模式配置

### 4.1 对齐方式

| 方式 | 特点 | 适用场景 |
|---|---|---|
| 边沿对齐 | 计数器 0→ARR→0→ARR... | 简单，频率固定 |
| 中心对齐 | 计数器 0→ARR→0→ARR... | 电机控制常用，减少谐波 |

**已确认：** 中心对齐（电机控制首选）

**优势：**
- 对称 PWM 波形，减少谐波
- 电流纹波更小
- EMC 性能更好
- 一个 PWM 周期产生两次更新事件（上溢和下溢）

### 4.2 PWM 模式

| 模式 | CCR < 计数器 | CCR > 计数器 |
|---|---|---|
| PWM Mode 1 | 低电平 | 高电平 |
| PWM Mode 2 | 高电平 | 低电平 |

**待确认：**
- [ ] 驱动板是高电平有效还是低电平有效？
- [ ] 是否需要 PWM Mode 1 或 Mode 2？

## 5. 互补输出与死区

### 5.1 互补输出

**6PWM 驱动：** 每个桥臂需要上下两个 MOSFET 交替导通

| 输出 | 引脚 | 说明 |
|---|---|---|
| CH1 | UH | U 相上桥臂 |
| CH1N | UL | U 相下桥臂 |
| CH2 | VH | V 相上桥臂 |
| CH2N | VL | V 相下桥臂 |
| CH3 | WH | W 相上桥臂 |
| CH3N | WL | W 相下桥臂 |

**已确认：** 6PWM 互补输出（有 CH1N/CH2N/CH3N 引脚）

### 5.2 死区配置

**死区目的：** 防止上下桥臂直通

**死区生成位置：**

| 位置 | 说明 |
|---|---|
| MCU 定时器 | STM32 高级定时器内置死区生成 |
| 驱动芯片 | 驱动板上的驱动芯片内置死区 |

**STM32 死区配置：**
- DTG（Dead Time Generator）寄存器
- 死区时间 = DTG × Tdtg（时钟周期）

**待确认：**
- [ ] 死区在 MCU 还是驱动芯片生成？（通常 STM32 高级定时器内置死区生成）
- [ ] 死区时间是多少？（通常 0.5~2μs）

## 6. 安全启动与故障处理

### 6.1 EN 引脚

**功能：** 使能/禁用驱动器

| 状态 | 说明 |
|---|---|
| EN=高 | 驱动器使能，PWM 输出有效 |
| EN=低 | 驱动器禁用，PWM 输出高阻 |

**安全流程：**
1. 初始化 PWM，但 EN=低（驱动器禁用）
2. 确认 PWM 输出正常（示波器验证）
3. 设置 EN=高（驱动器使能）
4. 开始 V/f 控制

**已确认：** SD 引脚 = PG10（Shutdown，驱动器使能/禁用）

**待确认：**
- [ ] SD 引脚是高电平有效还是低电平有效？（通常低电平有效 = 低电平禁用）

### 6.2 Fault 引脚

**功能：** 故障信号输入

| 状态 | 说明 |
|---|---|
| Fault=正常 | 驱动器正常工作 |
| Fault=故障 | 驱动器故障，PWM 输出禁用 |

**故障来源：**
- 过流保护
- 过温保护
- 欠压保护

**待确认：**

## 7. PWM 更新时机

### 7.1 更新事件

**STM32 定时器更新事件：**
- 计数器溢出时产生更新事件
- 可以触发 ADC 采样、DMA 传输等

**中心对齐模式：**
- 每个 PWM 周期产生两次更新事件（上溢和下溢）
- 通常在下溢事件时更新 CCR（占空比在中心对齐）

### 7.2 更新方式

| 方式 | 说明 | 适用场景 |
|---|---|---|
| 立即更新 | 直接写 CCR | 简单，但可能产生毛刺 |
| 影子寄存器 | 写 CCR 影子寄存器，更新事件时生效 | 电机控制常用 |
| DMA | DMA 自动传输 CCR 值 | 高性能，减少 CPU 负担 |

**待确认：**
- [ ] 使用影子寄存器还是立即更新？
- [ ] 是否需要 DMA？

## 8. 示波器验证项

### 8.1 验证清单

| 验证项 | 方法 | 期望结果 |
|---|---|---|
| PWM 频率 | 示波器测量周期 | 16kHz（62.5μs） |
| 占空比范围 | 改变 cmp 值，测量占空比 | 0~100% 线性变化 |
| 互补输出 | 测量 CH 和 CHN | 互补，无直通 |
| 死区时间 | 测量上升沿延迟 | 0.5~2μs |
| 相序 | 测量 A/B/C 相位差 | 120° 电角度 |
| 中心对齐 | 测量脉冲位置 | 脉冲在中心 |

### 8.2 测试步骤

**步骤 1：单相 PWM 验证**
1. 配置 TIM1 CH1 输出固定占空比
2. 示波器测量 PA8（TIM1_CH1）波形
3. 验证频率、占空比、死区

**步骤 2：三相 PWM 验证**
1. 配置 TIM1 CH1/CH2/CH3 输出
2. 示波器测量三相波形
3. 验证相序、相位差

**步骤 3：SVPWM 验证**
1. 运行 SVPWM 算法
2. 输出 cmp_a/b/c 到 TIM CCR
3. 示波器测量三相波形
4. 验证扇区切换、占空比变化

## 11. 驱动板硬件参数（V1R2）

### 11.1 电流采样参数

| 参数 | V1R2 | V1R1 |
|---|---|---|
| 采样电阻 | 0.01Ω | 0.02Ω |
| 偏置电压 | 1.65V | 1.24V |
| 放大倍数 | 8 | 8 |
| 灵敏度 | 0.08V/A | 0.16V/A |
| 理论零点 ADC | 2048 | 1539 |
| 每安培 ADC 计数 | 99 | 198 |

**电流计算公式（V1R2）：**
```c
I = (V_ADC - 1.65) / 0.08
```

**电流计算公式（V1R1）：**
```c
I = (V_ADC - 1.24) / 0.16
```

### 11.2 母线电压采样

| 参数 | V1R2 | V1R1 |
|---|---|---|
| 分压比 | 37 | 37 |
| 偏置电压 | 1.65V | 1.24V |
| 检测范围 | 0-48V | 0-70V |

**母线电压计算公式：**
```c
V_BUS = (V_ADC - 1.65) * 37  // V1R2
V_BUS = (V_ADC - 1.24) * 37  // V1R1
```

### 11.3 过流保护

| 参数 | 说明 |
|---|---|
| 阈值 | 约 10A |
| 响应时间 | 17-170ms（**不是瞬时保护**） |
| 保护持续 | 约 1.4s 后自动恢复 |
| FAULT 输出 | **没有引出到主控** |
| 比较基准 | V1R2: 2.45V, V1R1: 2.84V |

**过流保护真相：**
- 10% 占空比：约 170ms 触发
- 90% 占空比：约 17ms 触发
- 不是微秒级短路保护
- 保护后会定时恢复，不是永久锁死

### 11.4 已有的保护

| 保护 | 实现方式 |
|---|---|
| 输入反接阻断 | 两只 SS510 并联串联在正极 |
| 母线瞬态抑制 | SMBJ48CA TVS |
| PWM 隔离 | 6 只 TLP2362 |
| 上下管直通互锁 | 74HC86 + 74HC08 |
| 三相过流保护 | LMV331 比较器（慢） |
| MOS 默认关断 | 每管 18kΩ 门极下拉 |

### 11.5 没有的保护

| 保护 | 说明 |
|---|---|
| 硬件死区生成 | MCU 必须配置 |
| 持续过压关断 | 没有 |
| 欠压关断 | 没有独立比较器 |
| 过温关断 | 只有 ADC 检测，软件判断 |
| 快速短路保护 | 没有 |
| FAULT 输出 | 没有引出到主控 |
| 再生制动电阻 | 没有 |

### 11.6 调试安全建议

**⚠️ 10A 保护很慢，不能防硬短路！**

**必须做的安全措施：**
1. 使用限流电源
2. 串联保险丝
3. 初次调试用低母线电压（12V）
4. 低占空比测试
5. 示波器检查门极波形

**软件保护阈值建议：**
- 软件瞬时电流限制：3-5A
- 母线过压：低于 48V 留余量
- 母线欠压：按实际供电设置
- 过温停机：按实测设置
- 堵转保护：转速低 + Iq 持续偏高

### 11.7 建议的硬件改进

> 把 `Motor_SD_B` 或过流比较器输出引出，接到 STM32 的 `TIM1_BKIN`。这样过流发生时，TIM1 可以在硬件级立即关闭六路 PWM，同时软件还能知道发生了故障。
