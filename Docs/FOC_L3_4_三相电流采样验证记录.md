# 三相电流采样验证记录

本文记录三相电流 ADC 接入 VOFA+ 后的测试、分析、定位过程和当前结论。本文只记录已经完成实测或代码确认的内容；尚未完成的项目单独标记为待验证。

## 1. 测试目标

本轮测试用于确认：

1. 三相电流 ADC 数据是否能够稳定接收和解析；
2. 驱动器关闭与开启 50% PWM 时，采样零点是否发生明显变化；
3. ADC 触发点是否落在 PWM 换相瞬间；
4. 当前软件零点校准方案是否适合后续电流测量。

## 2. 测量链路

| 项目 | 配置 |
|---|---|
| MCU | STM32F407ZGTx |
| PWM 频率 | 16 kHz |
| TIM1 计数方式 | 中心对齐 |
| 电流 ADC | ADC1 注入 Rank 1~3 |
| 电流引脚 | PA3 / PA4 / PA6 |
| ADC 数据输出 | VOFA+ JustFloat |
| 电流换算 | `I = (raw - offset_raw) × VDDA / (4095 × Rshunt × Gain)` |
| 分流电阻 | 0.02 ohm |
| 运放增益 | 8 |

VOFA+ 普通模式前 6 个通道为：

```text
0: U 相电流
1: V 相电流
2: W 相电流
3: U 相电流 ADC 电压
4: V 相电流 ADC 电压
5: W 相电流 ADC 电压
```

## 3. 串口测试模式

通过串口文本命令切换，不启动 V/F 旋转：

```text
mode 0
mode 1
```

### mode 0：无驱动器输出

- PWM/ADC 采样链路保持运行；
- 驱动器 SD 关闭；
- V/F 状态机强制停止；
- 三相保持 50% 占空比。

### mode 1：50% PWM 静态测试

- 三相保持 50% 占空比；
- 驱动器 SD 开启；
- V/F 状态机强制停止；
- 不要求电机实际旋转。

## 4. 初始问题和排查思路

早期数据中观察到三相电流和在 PWM 开启后明显增加，因此最初怀疑 ADC 采样点位于上下管切换或死区附近。

检查 TIM1 配置后确认：

- TIM1 为中心对齐计数；
- CH1~CH3 使用 PWM1；
- 50% 占空比时三相比较值约为 `2625`；
- 原 CH4 ADC 触发点也是 `2625`。

因此原触发点可能正好位于三相 PWM 换相附近，容易采到开关瞬态、死区恢复过程或运放暂态响应。

## 5. 采样点修改

针对当前 50% PWM 静态测试，将 ADC 触发点从：

```text
CCR4 = 2625
```

调整为：

```text
CCR4 = 3937
```

代码定义为：

```c
#define ADC_TRIGGER_TICKS ((PWM_PERIOD * 3U + 2U) / 4U)
```

在当前中心对齐和 50% PWM 条件下，`3937` 位于低侧导通区中部，避开上下管切换和死区。

注意：该固定触发点只适用于当前 50% 静态测试。进入实际 SVPWM 后，应根据三相占空比和有效采样窗口动态选择触发位置。

## 6. 最新数据

本次只使用以下两份最新数据：

- `mode0(1).txt`
- `mode1(2).txt`

两份文件均按：

```text
20 × float32 + 00 00 80 7F
```

即每帧 84 字节进行解析。

### 6.1 完整帧数量

| 状态 | 完整帧数 |
|---|---:|
| mode 0 | 1161 |
| mode 1 | 3543 |

### 6.2 三相电流统计

| 状态 | 值1均值 | 值2均值 | 值3均值 | 三项和均值 | 和的标准差 |
|---|---:|---:|---:|---:|---:|
| mode 0，无 PWM 输出 | 0.136723 | 0.130071 | 0.125029 | **0.391822** | 0.089376 |
| mode 1，50% PWM | 0.132172 | 0.125209 | 0.119769 | **0.377150** | 0.091070 |
| mode 1 - mode 0 | -0.004551 | -0.004861 | -0.005260 | **-0.014672** | - |

如果使用 mode 0 的三个通道均值作为零偏补偿，mode 1 的补偿结果为：

```text
U: -0.004551 A
V: -0.004861 A
W: -0.005260 A
三相和: -0.014672 A
```

## 7. 最新结论

当前采样点调整为 `CCR4=3937` 后：

- 开启 50% PWM 没有导致采样偏置明显增加；
- 三个通道变化方向一致，变化量约为 `0.005 A`；
- PWM 开启前后三相和差值仅约 `0.0147 A`；
- 两种状态下的波动水平接近，标准差约为 `0.09 A`；
- 之前“50% PWM 额外引入约 `0.246 A` 偏置”的结论不适用于当前配置，已被本次数据修正。

因此，当前最大问题已经不是 PWM 开启导致的明显直流偏移，而是 mode 0 基线自身存在一定的时间漂移。

## 8. 基线漂移观察

mode 0 的三相和存在时间变化：

```text
前 500 帧：0.43717 A
后 500 帧：0.36968 A
```

mode 1 相对稳定：

```text
前 500 帧：0.39493 A
后 500 帧：0.39142 A
```

如果用接近后续测试时刻的 mode 0 后 500 帧作为基线：

```text
0.37715 - 0.36968 = 0.00747 A
```

这进一步说明 PWM 本身没有引入明显的额外直流采样偏移。

可能原因包括：

- 电流运放和模拟电源尚未热稳定；
- 1V24 或运放参考点随时间缓慢变化；
- 功率板、控制板和模拟地之间存在温漂或供电变化；
- 启动时零点校准过早，校准状态与正式运行状态不完全一致。

## 9. 当前方案

当前可以保留以下方案：

1. 使用 VREFINT 动态计算实际 VDDA；
2. 使用 `CCR4=3937` 作为当前 50% PWM 测试的 ADC 触发点；
3. 使用 mode 0 和 mode 1 进行驱动器状态对比；
4. 三相电流继续使用独立的 U/V/W 零点偏移；
5. 在零点和增益正式确认前，不接入过流保护和电流环。

## 10. 后续零点校准方案

正式启动校准建议如下：

```text
启动 ADC 和 PWM/CH4 采样
  -> 保持 mode 0，SD=0
  -> 等待约 500 ms，使 ADC、运放和功率板稳定
  -> 连续采集 1000~4096 帧
  -> 分别计算 U/V/W 原始 ADC 均值
  -> 保存为三相零点偏移
  -> 再进入 mode 1 或正常控制
```

采样数量建议：

- `1000` 帧约对应 62.5 ms，适合快速验证；
- `2048` 帧约对应 128 ms，适合作为当前默认值；
- `4096` 帧约对应 256 ms，适合降低随机噪声影响。

正式标定时应避免在刚上电、运放尚未稳定或功率板状态刚切换时立即取样。

## 12. 总结

本轮通过两种串口模式和最新数据，完成了从现象到定位的闭环：

```text
三相电流和异常
  -> 对比 mode 0 / mode 1
  -> 检查 TIM1 中心对齐和 CH4 触发点
  -> 将触发点从 2625 调整到 3937
  -> 重新采集完整 JustFloat 帧
  -> 确认 PWM 不再引入明显额外偏置
  -> 将后续重点转为热稳定后的零点校准和基线漂移
```

当前采样链路已经具备继续进行电流零点和增益标定的条件。
